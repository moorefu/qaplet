Issues and specs are tracked as local Markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. See `docs/agents/triage-labels.md`.

### Local validation

Before Windows/WSL diagnosis, compiler selection, or CI changes, read `docs/development.md` for execution-context evidence, the local check entry point, and CI failure triage.
