# M1 固定模块身份与失败，不提供原实例热更新

2026-11-02，用户在正式 M1 的 grill-with-docs 中确认：文件模块以 realpath 后的规范绝对 file URL 为身份，同一 URL 经统一模块注册表只求值一次，首次确定的身份和已加载源码保持到 Runtime 关闭；已有规范身份的加载、链接、求值失败也保存失败，修复后用新 Runtime 验证。QuickJS 的加载/解析失败、链接失败和求值失败保留的状态不同，且没有公开的完整模块图回滚接口，因此 M1 采用固定模块实例与失败记录，避免承诺在部分求值后可靠热更新。该缓存固定的是身份与加载结果，不冻结应用对象或 ESM live bindings；详见 [M1 设计 Q12/Q18](../../.scratch/qaplet-m1/design.md)。
