# M2 实际 ARM64 / 64K 本地矩阵

此入口消费 Ubuntu 固定供应的 SDK/APE，在锁定完整系统内核中执行适用合同。
`emulated-system` 单独记录，不填原生 ARM64 槽位。QEMU 的 TCG 时长只是观察值。
当前逐票结果与历史失败见[25 验证记录](../../.scratch/qaplet-m2/25-actual64k-validation.md)。

## 输入和执行

全部可复用 guest、工具链和 helper 输入仍使用主工作区物理 `.cache/`。
`arm64_guest.py` 的锁、签名链、实际页大小、machine/CPU/TCG、kernel/config/rootfs、
逐命令 START/END、串口和带 SHA256/长度 seal 的 RAM journal 必须完整。
每个 guest payload 都有传输前后 SHA256；supervisor timeout 或缺 START 不是成功。

- 普通目录：既有 `sdk_guest.py export` / `arm64_guest.py run` / `sdk_guest.py import`。
  当前包括 Host162、CLI53、M1 示例8、M2 示例6，共229项。
- 特殊目录：`sdk_m2_guest.py export` / `verify`，fault25、TTY13、mixed12。
  捕获 fixture 在执行前保存到独立目录，原始 stdout/stderr 和 native sidecar 逐字留存。
- 额外 CLI：`m2_guest_cli_matrix.py export` / `verify`，IO10、真实终端4、信号/清理16。
  普通 CLI53 加 IO/TTY14 覆盖 POSIX67；信号16单列。queue2 是公开 SDK relay Host，
  不宣称 CLI 满队列端到端。strong2 的 SDK 内部完整清理保留为未直接观察到的 `null`。
- 独立 backend：`m2_guest_probe_supply.py` 保存首次编译 C/helper 与 original-packer；
  `m2_guest_backend.py` 只读回放 waker19、process13、stdio19、TTY19及 pages64k12。
  这些 OS/libc 探针不链接 SDK archive，不能冒充产品源码二进制。
- 相关 waitid ABI：`m2_guest_abi.py export` / `verify`，明确消费固定 process-fault APE；
  实测 WNOWAIT、EINTR/EINVAL/ECHILD、opaque buffer 和 exit/kill/reap 顺序。
- 生命周期：共享 `sdk_m2_cycles.py` 编译固定 C9，再由 `m2_guest_cycles.py` 只读核验
  lifecycle1000、mixed100；三次 warmup 分别另计，真实 FD/thread 基线与清理计数必须存在。

`m2_guest_matrix.py` 接受 `--sdk-build --distribution --ordinary --special --cli --backend
--abi --cycles --report`，索引六个显式严格 consumer，并重读各原件索引和完整系统输入。
当前为319条 guest 命令、394条语义记录；1100实际循环单列，不用命令数替代循环数。
此本地索引不替代27的最终严格门禁。

## 辅助 fixture 的身份

`m2_fixture_binding.py` 保留原 SDK producer 身份，并对新目标记录独立 component binding。
它核对实际 C 根和递归 quoted include、公开头、双架构 archive、工具链/helper/loader，
以及实际 compile/link 的对象、库、包装符号和完整既有参数。多余对象、未绑定库/脚本、
异常标志或旧 transitive include 均被拒绝。旧执行报告不能改贴新 SKU。

共用 mixed child 的独立 READY 文件须先清旧文件，再验证实际 PID/PPid 与
`waitpid(WNOHANG)==0`。该原值只证明当时 child 活着；ret0 时初始化的 raw status
没有有效退出含义。Stop 后由 SDK 独有 reap，observer 不再提前 wait/reap。

## 只读工具检查

默认 unit tests 检查 capture/目录和输入闭包；显式给
`QAPLET_M2_GUEST_REPORT=.../s4-cli-guest.json` 后执行
`python3 -m unittest discover -s tests/contracts -p test_m2_guest_observations.py -v`，
先验证真实原件 baseline，再拒绝缺真实 signal trace、被改终端恢复、重置五秒预算、
late hint 身份复用、把 strong 的 null 擅改 true、缺 journal seal、重新 seal 后缺 START、
传输后哈希变化和 supervisor timeout。检查不重新运行产品。

新 export/只读报告使用唯一输出路径，已存在即拒绝。改变只读解释器可重新解释同一原件，
不会重写、重命名或补造旧报告；新产品输入则需要新实际执行。
